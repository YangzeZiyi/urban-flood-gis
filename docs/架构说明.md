# 架构说明

## 四层结构

```
┌─────────────────────────────────────────────┐
│  前端展示层  Vue3 + Vite + Cesium            │
│  三维地球 · 风险区着色 · 时间轴 · 点击查询   │
└──────────────────┬──────────────────────────┘
                   │ HTTP / JSON (GeoJSON)
┌──────────────────▼──────────────────────────┐
│  后端服务层  Spring Boot 3 + MyBatis         │
│  REST API · 空间查询编排 · 风险模型调用      │
└──────────────────┬──────────────────────────┘
                   │ JDBC
┌──────────────────▼──────────────────────────┐
│  空间数据层  PostgreSQL 18 + PostGIS 3.7     │
│  flood_zone · rain_record · risk_snapshot    │
└──────────────────▲──────────────────────────┘
                   │ psycopg2
┌──────────────────┴──────────────────────────┐
│  数据处理层  Python + GeoPandas + Rasterio   │
│  爬虫采集 · DEM 处理 · 易涝区提取 · 入库     │
└─────────────────────────────────────────────┘
```

## 模块职责

### M1 数据采集（`pipeline/fetch/`）
- 抓取目标城市降雨数据（API 或网页）
- 下载 SRTM 30m DEM
- 下载 OSM 路网 / 水系 / 行政区
- 统一坐标系到 EPSG:4326
- 输出至 `data/raw/` 与 `data/clean/`

### M2 空间处理（`pipeline/process/`）
- DEM 填洼、坡度、汇流累积量计算
- 提取低洼易涝区（高程低 + 坡度小 + 汇流大）
- 生成风险栅格与矢量面
- 输出至 `data/output/`

### M3 空间数据库（`sql/`）
- 5 张核心表 + GiST 空间索引
- 视图直接输出 GeoJSON
- 详见 `sql/01_schema.sql`

### M4 后端接口（`backend/`）
| 接口 | 说明 |
|---|---|
| `GET /api/zones` | 全部易涝区 GeoJSON |
| `GET /api/zones/{id}` | 单个易涝区详情 |
| `GET /api/rain?start=&end=` | 降雨序列 |
| `GET /api/risk?time=` | 指定时刻风险分布 |

### M5 风险模型（`backend/.../service/RiskService.java`）
两层设计：

**第一层 · 加权评分（必做）**
```
Risk = w1 × 降雨强度归一化
     + w2 × 地形低洼度归一化
     + w3 × (1 - 排水能力归一化)

初始权重：w1=0.45, w2=0.35, w3=0.20
输出 0~1，按阈值分为 1低 / 2中 / 3高 / 4极高
```

**第二层 · 马尔科夫链预测**
- 用历史降雨序列构建状态转移矩阵
- 预测未来 7 天降雨状态
- 输出"未来风险趋势"

### M6 三维可视化（`frontend/`）
- Cesium Viewer + 影像底图
- 风险区 `Entity` 多边形，按等级填色 + 半透明
- 时间轴滑块 → 切换 `risk_snapshot.time_bucket`
- 点击拾取 → 弹窗显示详情
- 图例 + 图层开关

### M7 部署交付
- 前端 `npm run build` → 静态文件
- 后端 `mvnw package` → jar
- Nginx 或云服务器部署
- README + 演示视频

## 关键技术决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 几何返回方式 | `ST_AsGeoJSON()` 转字符串 | 避开 hibernate-spatial 的复杂配置 |
| 坐标系 | 全流程 EPSG:4326 | Cesium 原生支持，免转换 |
| 风险区渲染 | Cesium `Entity` 而非 `Primitive` | 开发快，便于拾取交互 |
| 时间轴数据 | 预生成 `risk_snapshot` | 避免实时计算拖慢前端 |

## 数据流

```
公开数据源
   ↓ (Python 爬取/下载)
data/raw 原始数据
   ↓ (清洗 + 坐标统一)
data/clean 干净数据
   ↓ (空间分析: 填洼/坡度/汇流)
data/output 风险图层
   ↓ (psycopg2 写入)
PostGIS flood_zone / risk_snapshot
   ↓ (Spring Boot 查询 + 模型)
REST API (GeoJSON)
   ↓ (fetch)
Cesium 三维场景
```

一、下载安装包

打开：https://www.enterprisedb.com/downloads/postgres-postgresql-downloads

页面是一个版本表格，找到 18.7 那一行，点 Windows 列的 Download：

你要选的说明
版本 18.718 发布于 2025 年 9 月，已修到第 7 个补丁版；PostGIS 3.7 官方 Bundle 明确支持 18–19
系统 Windows x86-64你的机器是 x64，注意别点 ARM64 或 32 位
文件 .exe约 350MB，就是安装器
为什么是 18，不是最新的 19？
① PG 19.0 是 2026 年 9–10 月才发的首个大版本，PostGIS 3.7 的 Windows Bundle 到 2026 年 11 月 11 日才跟上——太新，容易当小白鼠。
② PG 18.7 已修到第 7 个补丁版，稳；PostGIS 官网原文写「Bundle 3.7.0 installers for PostgreSQL 18–19」，Stack Builder 里一定选得到。
③ 也不用退回 17：PostGIS 官网说 3.7 的 15–17 版 Bundle 还在 "on the way"（没出），Stack Builder 里能不能选到旧版反而不确定。
一句话：18 是「够新 + 够稳 + PostGIS 确定支持」的唯一交集。

四、装完必做三件事

1. 把 bin 目录加进 PATH

不加的话，你在任意目录敲 psql 都会报"不是内部或外部命令"。

Win+R → 输入 sysdm.cpl → 高级 → 环境变量 → 在下半部分系统变量里找到 Path → 编辑 → 新建：

D:\dev\PostgreSQL\18\bin

确定保存，然后关掉所有终端窗口重新开。

2. 建项目数据库

新开 CMD，执行（会提示输入密码，就是你第 5 屏设的那个）：

psql -U postgres

进入 psql 后，逐行执行：

CREATE DATABASE floodgis;
\c floodgis
CREATE EXTENSION postgis;
SELECT postgis_version();
\q
最容易犯的错：忘了 \c floodgis。
CREATE EXTENSION postgis 是装在某一个具体的数据库里的，不是装在 PostgreSQL 全局。如果你在默认的 postgres 库里建，项目连 floodgis 时会报 type "geometry" does not exist。
一定要先 \c floodgis 切过去，再建扩展。

3. 给项目建个专用连接（可选但推荐）

暂时用 postgres 超级用户没问题。等后端跑通了，再建专用账号更规范：

CREATE USER gisuser WITH PASSWORD 'gis123456';
GRANT ALL PRIVILEGES ON DATABASE floodgis TO gisuser;
\c floodgis
GRANT ALL ON SCHEMA public TO gisuser;

五、验证成功（4 条命令）

新开 CMD，逐条跑，全部正常才算装好：

命令期望结果
psql --versionpsql (PostgreSQL) 18.x
psql -U postgres -c "SELECT version();"输出 PostgreSQL 18.x on x86_64-windows...
psql -U postgres -d floodgis -c "SELECT postgis_version();"3.5 USE_GEOS=1 USE_PROJ=1 USE_STATS=1
psql -U postgres -d floodgis -c "SELECT ST_AsText(ST_Point(114.3,30.5));"POINT(114.3 30.5)
第 4 条是关键。它能输出 POINT(114.3 30.5)，说明 PostGIS 的空间函数真的能用了——不是只装了个壳。到这一步，你的空间数据库就彻底就绪了。

六、装错了怎么彻底重来

如果中途搞乱了（比如 PostGIS 版本选错、路径选错、密码忘了），别在残骸上修补，彻底卸干净重装更快：

  1. 控制面板 → 卸载程序 → 卸载 PostGIS 3.7 Bundle。
  2. 再卸载 PostgreSQL 18。
  3. 手动删掉残留目录：D:\dev\PostgreSQL（整个文件夹）。
  4. 删掉数据目录（如果建在别处）：D:\dev\PostgreSQL\18\data。
  5. 检查服务是否残留：Win+R → services.msc → 找 postgresql-x64-18，如果还在，右键停止后删除（用管理员 CMD 执行 sc delete postgresql-x64-18）。
  6. 重启电脑，然后从头按本文档再装一遍。
判断要不要重装：如果 CREATE EXTENSION postgis 报「版本不兼容」或「extension "postgis" is not available」，基本就是 PostGIS Bundle 装错了版本或装错了路径——重装一次比调试快得多。

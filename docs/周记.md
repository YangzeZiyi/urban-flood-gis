**卡点（都是环境类，已全部解决，记下来免得再踩）**
- `pom.xml` / `settings.xml` 的 XML 注释里写了连续 `--` 虚线，Maven 直接拒绝解析
- npm 11 默认拦截 install scripts，esbuild 缺二进制 → `npm install-scripts approve esbuild`
- YAML 1.1 把 `010704` 当八进制解析成 4516，纯数字密码必须加引号
- IDEA 里 `backend` 只是普通文件夹（没导入 Maven 模块），所以没有运行三角
- VS Code 终端报"禁止运行脚本"→ PowerShell 执行策略改 `RemoteSigned`
- 改 `application.yml` 后 devtools 不重启，必须手动停+重跑
- 底图技术选型：OSM 国内不通（超时）、天地图无 key 返回 418、高德可用但 GCJ-02 偏移 300~500m

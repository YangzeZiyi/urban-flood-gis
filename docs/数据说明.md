# 数据说明

> 全部数据均为公开可获取来源，不涉及任何涉密或内部资料。

---

## 一、数据清单

### 1. 降雨数据

| 项 | 内容 |
|---|---|
| 用途 | 驱动风险模型、时间轴回放 |
| 来源 | 公开气象 API（如和风天气免费额度）或气象站公开数据 |
| 格式 | JSON / CSV |
| 关键字段 | 站点编号、观测时刻、降雨量(mm) |
| 更新频率 | 按需抓取，开发期用历史数据即可 |

**注意事项：**
- 免费 API 有调用次数限制，抓取要加延时
- 抓下来的数据先落 `data/raw/`，避免重复请求
- 时间统一用本地时间，入库为 `TIMESTAMP` 不带时区

### 2. DEM 高程数据

| 项 | 内容 |
|---|---|
| 用途 | 计算坡度、汇流、判定低洼区 |
| 来源 | SRTM 30m（公开免费，覆盖全国） |
| 格式 | GeoTIFF |
| 分辨率 | 30 米 |
| 坐标系 | 原始为 EPSG:4326 |

**注意事项：**
- 单幅 SRTM 覆盖 1°×1°，城市范围通常需要拼接 2–4 幅
- 拼接用 `rasterio.merge`
- 文件较大，不进 Git

### 3. OSM 路网 / 水系 / 行政区

| 项 | 内容 |
|---|---|
| 用途 | 底图辅助层、汇流路径参考 |
| 来源 | Geofabrik（按省打包 .osm.pbf）或 Overpass API |
| 格式 | .osm.pbf → 转为 GeoJSON / Shapefile |
| 坐标系 | 原始 WGS84 |

**注意事项：**
- .pbf 文件很大（省级几百 MB），只提取需要的图层
- 可用 `osmium` 或 `pyrosm` 提取

### 4. 行政区边界

| 项 | 内容 |
|---|---|
| 用途 | 范围裁剪、统计分区 |
| 来源 | 公开 GeoJSON 数据 |
| 坐标系 | **需特别注意**：部分公开数据是 GCJ-02（火星坐标） |

**重要：** 如果用高德/腾讯系的数据，坐标是 GCJ-02，与 WGS84 有几百米偏移。必须做坐标纠偏，否则图形会整体偏移。


## 三、字段定义

### flood_zone（易涝风险区）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGSERIAL | 主键 |
| name | VARCHAR(100) | 区域名称 |
| risk_level | SMALLINT | 1低 2中 3高 4极高 |
| max_depth | NUMERIC(6,2) | 最大积水深度（米） |
| area_m2 | NUMERIC(14,2) | 面积（平方米） |
| rain_mm | NUMERIC(7,2) | 触发该风险的降雨量 |
| description | TEXT | 描述/建议 |
| geom | GEOMETRY(Polygon,4326) | 空间几何 |

### risk_snapshot（时间轴快照）

| 字段 | 类型 | 说明 |
|---|---|---|
| time_bucket | TIMESTAMP | 时间片，如整点 |
| zone_id | BIGINT | 关联 flood_zone |
| risk_level | SMALLINT | 该时刻风险等级 |
| water_depth | NUMERIC(6,2) | 该时刻积水深度 |

## 四、合规提醒

- 地图底图使用合规来源（天地图需申请 key，或 Cesium 官方影像）
- **不使用未经审核的地图数据对外展示**
- 国内公开发布的地图，边界必须符合国家标准
- 本项目为个人作品，不外链公网展示时风险较低，但如果部署上线，需使用合规底图

---

## 五、数据验证方法

做完易涝区提取后，用真实新闻验证：

1. 搜索"目标城市 + 暴雨 + 积水点"，找 2–3 个具体地点
2. 在 QGIS 或前端上把模型算出的高风险区叠上去
3. 看是否大致吻合

**不需要完全一致**，大致对得上就说明逻辑成立。作品集项目重在链路完整与逻辑自洽，不在学术精度。
